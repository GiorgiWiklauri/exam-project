# Exam Project

ეს პროექტი შექმნილია Git-ისა და GitHub-ის პრაქტიკული დავალებისთვის.

## ფაილები
- `index.html` — პროექტის მთავარი HTML გვერდი.
- `README.md` — პროექტის მოკლე აღწერა.

დავალების ფარგლებში შესრულდება Git-ის ინიციალიზება, commit-ები, branch-ების შექმნა,
GitHub-ზე ატვირთვა, merge და merge conflict-ის მოგვარება.
